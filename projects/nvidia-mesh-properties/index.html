Research examples

The question

The challenge.

A mesh describes geometry and appearance, but many downstream tasks need meaningful parts and an estimate of what those parts are made of.

The approach

The central idea.

Aggregate visual foundation-model features across rendered views into a consistent 3D feature field. Use part grouping and multimodal reasoning to estimate semantic and material labels.

Measured impact

The results.

The framework’s material estimates were used to estimate object mass. These research-draft results improve some error measures and worsen another.

Evaluation context

Research-draft results improve ADE, ALDE and MnRE, but APE worsens. Material properties are inferred estimates. The patent is a published application.

Behind the result

How it works.

  1. 01

    Render the mesh from multiple views and extract image features and segmentation masks.

  2. 02

    Refine and aggregate features into a consistent 3D feature field, then cluster the mesh into parts.

  3. 03

    Use multimodal reasoning to label parts and estimate materials, grounding those labels back onto the 3D asset.

From geometry to material-aware parts

The framework links 2D foundation-model features across rendered views of a 3D asset, producing consistent parts that can be assigned semantic and material labels.

Research contributions

  • Developed a framework connecting 3D part segmentation with material identification.
  • Combined visual foundation models and multimodal reasoning for physical-property assignment.
