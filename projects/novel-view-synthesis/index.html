Novel view synthesis at scale · ICCV 2025

Large-scale 3D training with synthetic data.

Training large vision transformers to create new views of a scene, using generated examples to expand the available training data.

Co-first author · Google · Dec 2024 – Mar 2025

Overview

Diffusion-generated images provide more training examples. Token disentanglement helps the model learn from them while reducing the visual errors that carry into the reconstructed scene.

Examples

Problem

Large 3D models need many views of many scenes. Generating those views can expand the training data, but the generated images often contain visual errors that the model can learn to repeat.

Approach

Give the input views and output queries separate representations. This helps the transformer use generated training views while reducing the errors that pass into its reconstructed scene.

Results

Tok-D produces views closer to the reference images in the paper’s reconstruction tests. The table reports PSNR, an image-fidelity measure where higher is better.

Evaluation context

Method

  1. 01

    Generate additional camera-conditioned views with CAT3D, a pretrained multi-view diffusion model.

  2. 02

    Use separate modulation for source and target tokens to improve feature alignment when training with synthetic views.

  3. 03

    Train the view-synthesis transformer on real and generated observations, then evaluate reconstruction on both familiar and unseen scene distributions.

Token disentanglement

Tok-D is a transformer block for novel view synthesis that distinguishes source-image tokens from target-view tokens through layer-wise modulation. It addresses feature alignment that can make a reconstruction model sensitive to artifacts in synthetic views.

The goal is to learn a model that reconstructs new camera views across scenes, without optimizing a separate representation for every test scene.

Contributions

  • Introduced source/target token disentanglement to reduce the effect of synthetic-view artifacts.
  • Improved PSNR over LVSM by 1.13 dB on RealEstate10K and 1.64 dB on DL3DV in the published in-distribution, real-data comparison.
  • Co-first author. The reported experiments use eight H100 GPUs.
