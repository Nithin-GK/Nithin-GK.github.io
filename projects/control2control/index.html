The question

The challenge.

Changing an object’s shape or position can inadvertently regenerate the rest of the image. Spatial controls need to support the requested edit while retaining content elsewhere.

The approach

The central idea.

Estimate the changed region from source/target attention features. Transfer target keys and values inside the mask and source keys and values outside it while denoising.

Measured impact

What the examples show.

The draft illustrates sketch-guided changes, object movement and pose edits using pretrained spatial controllers. The examples demonstrate the pipeline’s behavior; a completed quantitative benchmark is not available.

Evaluation context

The draft provides qualitative evidence, not a completed quantitative benchmark. Large edits and imperfect masks can change identity or background.

Behind the result

How it works.

  1. 01

    Run source and target diffusion branches with the original and user-edited spatial conditions.

  2. 02

    Accumulate self-attention features over intermediate denoising steps. Filter their source/target difference with a low-rank decomposition and threshold it to estimate the edit mask.

  3. 03

    Blend target keys and values inside the mask with source keys and values outside it at selected layers, then complete denoising.

Revitalized attention transfer

Revitalized attention transfer is a mask-guided self-attention operation for diffusion image editing. At selected layers, it uses the target branch's keys and values within the edit region and the source branch's keys and values elsewhere.

K̂t = M ⊙ Kt + (1 − M) ⊙ Ks

V̂t = M ⊙ Vt + (1 − M) ⊙ Vs

M is the edit mask: 1 inside the changed region and 0 outside it. The subscripts t and s denote the target and source branches, respectively.

The target branch retains its own queries. This lets the edited object attend to the original scene while giving the changed region freedom to follow the new spatial condition.

Research contributions

  • Built a training-free diffusion pipeline for interactive edits using sketches, poses or layouts.
  • Estimated edit masks from source/target self-attention differences using low-rank filtering.
  • Used masked key/value transfer to support changes while retaining source content in unchanged regions.
