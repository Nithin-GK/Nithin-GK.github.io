Steered Diffusion

Guide a pretrained image generator to restore images or follow new conditions, without training a separate generator for each task.

First author

How it works

  1. Choose a pretrained diffusion generator and an auxiliary model that represents the desired task or condition.

  2. Construct a task loss that measures agreement with the input condition during sampling.

  3. Use the guidance signal to steer denoising, adapting the generator to the task without training a separate task-specific generator.

Energy-based diffusion steering

Steered Diffusion turns a pretrained diffusion generator into a conditional generator at inference time. A pretrained inverse model defines a loss for the requested condition, and that loss steers the denoising trajectory toward an image that satisfies it.

For example, an inverse model can estimate a semantic label or a degraded observation from the current image. Comparing that prediction with the desired condition supplies a guidance signal.

Results

Each row compares one task with its baseline. The 8× super-resolution test uses 300 CelebA images. Lower FID indicates better distributional image quality, while higher PSNR indicates closer agreement with the reference.
