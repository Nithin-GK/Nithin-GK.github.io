The question

The challenge.

Conditional generation often requires a dedicated model for each task. A strong unconditional diffusion generator already contains useful image knowledge, but needs a way to follow new constraints.

The approach

The central idea.

Guide the implicit clean-image prediction with a pretrained task function during denoising. The same formulation supports image restoration, semantic conditions and combined guidance.

Behind the result

How it works.

  1. 01

    Choose a pretrained diffusion generator and an auxiliary model that represents the desired task or condition.

  2. 02

    Construct a task loss that measures agreement with the input condition during sampling.

  3. 03

    Use the guidance signal to steer denoising, adapting the generator to the task without training a separate task-specific generator.

Energy-based diffusion steering

Steered Diffusion turns a pretrained diffusion generator into a conditional generator at inference time. A pretrained inverse model defines a loss for the requested condition, and that loss steers the denoising trajectory toward an image that satisfies it.

For example, an inverse model can estimate a semantic label or a degraded observation from the current image. Comparing that prediction with the desired condition supplies a guidance signal.

Research contributions

  • Introduced the first plug-and-play framework applicable to both image-to-image translation and label-conditioned synthesis in the studied setting.
  • Used pretrained auxiliary networks and energy-based guidance to express new conditions at inference time.
  • Supported tasks including inpainting, colorization, super-resolution and semantic generation without task-specific generator training.
